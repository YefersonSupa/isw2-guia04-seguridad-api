=== CASO PRÁCTICO 01: SPORTRESERVE CO. (ANTES vs DESPUÉS) ===
[Hallazgo A - IDOR] GET /api/reserva?id=105&user_id=1
  ANTES  (app_vulnerable.py): HTTP 200 -> EXPONE reserva de User_B (owner=2)
  DESPUÉS(app_segura.py)    : HTTP 403 -> {"error": "Acceso denegado: la reserva pertenece a otro usuario."}
[Hallazgo B - SQLi] GET /api/usuarios/buscar?correo=' OR '1'='1
  ANTES  (app_vulnerable.py): HTTP 200 -> FILTRA 3 usuarios completos
  DESPUÉS(app_segura.py)    : HTTP 400 -> {"error": "Formato de correo electrónico inválido"}
[Hallazgo C - XSS]  GET /comentarios?nombre=<script>alert(1)</script>
  ANTES  (app_vulnerable.py): HTTP 200 -> <script> crudo inyectado=True
  DESPUÉS(app_segura.py)    : HTTP 200 -> escapado=True | CSP=default-src 'self'; script-src 'none'; object-src 'none'; frame-ancestors 'none'
